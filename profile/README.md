# wearenotabank

> **Not a bank.** The projects in this organisation take no deposits, grant no credit and hold no one else's funds.

wearenotabank makes developer tools for EVM chains: smart contracts, SDKs and the libraries beneath them, with a focus
on Dart. It is a product of Cube Algos UG (haftungsbeschränkt), which runs this organisation and publishes the source
code, documentation and release records here.

| Repository | What it does | Licence |
| --- | --- | --- |
| [viem_dart](https://github.com/wearenotabank/viem_dart) | A pure-Dart port of viem: one EVM client for Dart servers and CLIs, Flutter and Jaspr. | MIT |
| `multi-feed-oracle-contracts` | An immutable price oracle that answers any pair from one address. | Apache-2.0 |
| `hooked-userop` | A TypeScript SDK that lets a Safe pay its gas in a token CoW Protocol can trade. A Dart SDK is planned. | Apache-2.0 |
| `auto-sweep-contracts` | Sweeps a Safe's tokens on every chain into one token on one chain, through CoW Protocol and Circle CCTP. Contracts with TypeScript and Dart SDKs, in early development. | Contracts BUSL 1.1 (source-available), SDKs Apache-2.0 |

**Review previews.** Every public repository here is published to be read and reviewed before its first release. No contract is
deployed, no release is tagged and no package is on a registry yet.

Safe, CoW Protocol, Circle and viem are named to say what the software works with. That implies no affiliation or
endorsement.
