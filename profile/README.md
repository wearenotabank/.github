# wearenotabank

> **Not a bank.** The projects in this organisation take no deposits, grant no credit and hold no one's funds.

wearenotabank is the GitHub organisation of developer content published by Cube Algos UG (haftungsbeschränkt): source code, documentation and release records of open-source software projects. Its repositories are published as review previews, open to read and to review. A preview is not a release, and Cube Algos UG has deployed nothing from it. The first is [multi-feed-oracle-contracts](https://github.com/wearenotabank/multi-feed-oracle-contracts), the contracts of a price oracle that answers any pair from one address.
